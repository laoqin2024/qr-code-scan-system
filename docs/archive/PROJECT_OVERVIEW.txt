## 📋 项目概述

这是一个功能完整的 Web 应用程序，用于管理二维码扫码录入和查询。系统支持：

✅ 多用户角色管理（管理员/操作员）
✅ 客户信息维护（配置期望二维码长度）
✅ 产品型号维护（关联客户）
✅ 二维码扫码录入（实时长度校验）
✅ 扫码记录查询（多维度筛选）
✅ 异常检测与提示（长度不足/超出）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🎨 功能亮点

### 1. 智能长度校验
系统会自动比较二维码的实际长度与客户配置的期望长度：
  ✅ 实际长度 = 期望长度 → 正常（绿色显示）
  ❌ 实际长度 < 期望长度 → 长度不足（红色警告）
  ❌ 实际长度 > 期望长度 → 长度超出（红色警告）

### 2. 实时反馈
  • 前端实时显示长度校验结果
  • 后端保存时再次校验
  • 异常记录自动标记
  • 友好的错误提示

### 3. 灵活查询
  • 支持多维度筛选
  • 实时查询结果
  • 异常记录高亮
  • 详细信息展示

### 4. 权限控制
  • 管理员：完全权限
  • 操作员：扫码和查询
  • 路由保护
  • API 鉴权

## 🎯 使用场景示例

### 场景1: 正常扫码
1. 登录系统（admin / admin）
2. 进入"扫码录入"页面
3. 选择"客户A"（期望长度：20）
4. 选择"产品A1"
5. 输入二维码：12345678901234567890
6. 显示：✅ 长度正确（绿色）
7. 点击"提交保存"
8. 提示：✓ 二维码校验通过

### 场景2: 异常扫码
1. 选择"客户A"（期望长度：20）
2. 选择"产品A1"
3. 输入二维码：123456（长度6）
4. 显示：✗ 长度异常（红色警告）
5. 点击"提交保存"
6. 提示：✗ 二维码校验失败：长度不足
7. 记录保存，标记为异常

### 场景3: 查询异常记录
1. 进入"查询记录"页面
2. 状态选择"异常"
3. 查看所有长度异常的记录
4. 红色高亮显示
5. 查看详细的异常原因
