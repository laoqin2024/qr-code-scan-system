## 📞 使用说明

### 快速启动
```bash
# 方式1: 使用启动脚本
./start.sh

# 方式2: 手动启动
cd backend && npm run dev &
cd frontend && npm run dev &
```

### 停止服务
```bash
# 方式1: 使用停止脚本
./stop.sh

# 方式2: 手动停止
pkill -f "tsx watch"
pkill -f "vite"
```

### 重新初始化数据库
```bash
cd backend
rm ../db.sqlite
npm run init
```
