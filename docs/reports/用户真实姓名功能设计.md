# 用户真实姓名功能 - 设计方案

## 📋 需求分析

### 当前问题
- 用户表只有 username（登录账号）
- 扫码记录显示的是账号名（如 operator_zhang）
- 不够直观，难以识别具体人员

### 新需求
- 添加真实姓名字段（display_name 或 real_name）
- 扫码记录显示真实姓名（如"张三"）
- 用户管理界面显示姓名和账号

## 🎯 设计方案

### 1. 数据库设计

```sql
-- 添加真实姓名字段
ALTER TABLE users ADD COLUMN display_name TEXT;

-- 为现有用户设置默认姓名（使用用户名）
UPDATE users SET display_name = username WHERE display_name IS NULL;

-- 创建索引（可选，用于搜索）
CREATE INDEX idx_users_display_name ON users(display_name);
```

### 2. 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| username | TEXT | 登录账号（唯一） | operator_zhang |
| display_name | TEXT | 真实姓名/显示名称 | 张三 |
| role | TEXT | 角色 | operator |

## 📊 数据迁移策略

### 方案1：使用用户名作为默认姓名
```sql
UPDATE users SET display_name = username WHERE display_name IS NULL;
```

### 方案2：根据角色设置默认姓名
```sql
UPDATE users SET display_name = 
  CASE 
    WHEN role = 'super_admin' THEN '系统管理员'
    WHEN role = 'customer_admin' THEN '客户管理员_' || id
    WHEN role = 'operator' THEN '操作员_' || id
    WHEN role = 'viewer' THEN '查看者_' || id
    ELSE username
  END
WHERE display_name IS NULL;
```

### 方案3：手动设置（推荐）
```sql
-- 为已知用户设置真实姓名
UPDATE users SET display_name = '系统管理员' WHERE username = 'admin';
UPDATE users SET display_name = '张三' WHERE username = 'operator_zhang';
UPDATE users SET display_name = '李四' WHERE username = 'operator_li';

-- 其他用户使用用户名
UPDATE users SET display_name = username WHERE display_name IS NULL;
```

## 🎨 显示优先级

### 规则
1. **优先显示姓名**：display_name
2. **备用显示账号**：username（当姓名为空时）
3. **详细信息**：姓名 (账号)

### 示例
```typescript
// 工具函数
function getUserDisplayName(user: User): string {
  return user.display_name || user.username;
}

function getUserFullInfo(user: User): string {
  if (user.display_name && user.display_name !== user.username) {
    return `${user.display_name} (${user.username})`;
  }
  return user.username;
}
```

## 🔒 安全考虑

### 1. 姓名唯一性
- ❌ 不要求姓名唯一（可能有重名）
- ✅ 登录账号必须唯一
- ✅ 通过 user_id 区分不同用户

### 2. 姓名验证
```typescript
// 后端验证
if (!display_name || display_name.trim().length === 0) {
  return res.status(400).json({ error: '姓名不能为空' });
}

if (display_name.length > 50) {
  return res.status(400).json({ error: '姓名长度不能超过50个字符' });
}
```

### 3. 隐私保护
- 姓名仅在系统内部显示
- 不对外暴露
- 审计日志记录姓名变更
