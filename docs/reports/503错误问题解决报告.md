# 503 错误问题解决报告

## 📋 问题描述

**用户反馈：**
- 部署脚本配置前端端口为 6006
- 访问 http://192.168.8.91:6006 出现 503 错误
- Nginx 服务正常运行

**初步分析：**
- ✅ Nginx 配置使用了正确的 `$FRONTEND_PORT` 变量
- ✅ Nginx 正确监听 6006 端口
- ❌ 503 错误表示后端服务无响应

---

## 🎯 根本原因

用户在配置 `SERVER_HOST` 时填写了 `0.0.0.0`，导致两个问题：

### 问题 1：server_name 配置错误

**错误配置：**
```nginx
server {
    listen 6006;
    server_name 0.0.0.0;  # ❌ 错误！
    ...
}
```

**原因：**
- `0.0.0.0` 不是有效的 `server_name` 值
- `server_name` 用于域名匹配，不是监听地址
- 应该填写实际的 IP、域名或 `_`（通配符）

### 问题 2：概念混淆

**用户误解：**
> "我以为 SERVER_HOST 配置成 0.0.0.0 就能让外部访问"

**实际情况：**
- `SERVER_HOST` → Nginx 的 `server_name` → 域名匹配
- 外部访问由 `listen` 指令决定
- `listen 6006` 默认就是监听所有接口（0.0.0.0:6006）

---

## ✅ 解决方案

### 1. 正确的配置理解

| 配置项 | 作用 | 正确值 | 错误值 |
|--------|------|--------|--------|
| `listen` | 监听端口和地址 | `6006` 或 `0.0.0.0:6006` | - |
| `server_name` | 域名匹配 | `192.168.8.91` 或 `_` | `0.0.0.0` |
| `proxy_pass` | 后端地址 | `http://localhost:3001` | `http://0.0.0.0:3001` |

### 2. 修复步骤

```bash
# 1. 编辑 Nginx 配置
sudo nano /etc/nginx/sites-available/scan-code

# 2. 修改 server_name
# 将：server_name 0.0.0.0;
# 改为：server_name 192.168.8.91;  # 或 _

# 3. 测试配置
sudo nginx -t

# 4. 重启 Nginx
sudo systemctl restart nginx

# 5. 确保后端服务运行
pm2 list
pm2 restart scan-code-backend  # 如需要

# 6. 测试访问
curl http://localhost:6006
```

### 3. 使用自动修复脚本

```bash
cd /opt/scan-code
bash scripts/fix-503.sh
```

## 📚 知识点总结

### 1. 0.0.0.0 的正确用法

**可以使用的地方：**
```nginx
listen 0.0.0.0:6006;  # ✅ 监听所有接口
```

```javascript
// Node.js 后端
app.listen(3001, '0.0.0.0');  // ✅ 监听所有接口
```

**不能使用的地方：**
```nginx
server_name 0.0.0.0;           # ❌ 不是有效的域名
proxy_pass http://0.0.0.0:3001; # ❌ 无法连接
```

### 2. Nginx 配置层次

```
外部访问
    ↓
listen 6006 (监听端口，决定是否能访问)
    ↓
server_name (域名匹配，选择虚拟主机)
    ↓
location / (路径匹配，处理请求)
    ↓
proxy_pass (反向代理到后端)
```

### 3. 503 错误的本质

- **不是** Nginx 配置错误
- **不是** 端口监听问题
- **而是** 后端服务无法响应

**常见原因：**
1. 后端服务未启动（最常见）
2. 后端服务崩溃
3. 后端端口配置错误
4. 数据库连接失败
5. 权限问题

```bash

前端端口: 6006 (或 80)

```

### 2. Nginx 配置

```nginx
server {
    listen 6006;                      # 监听端口
    server_name _;                    # 匹配所有（推荐）
    
    location / {
        root /opt/scan-code/frontend/dist;
        try_files $uri $uri/ /index.html;
    }
    
    location /api {
        proxy_pass http://localhost:3001;  # 后端地址
        ...
    }
}
```
