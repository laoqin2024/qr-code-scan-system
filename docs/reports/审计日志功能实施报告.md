## 🔧 技术实现

### 后端实现

**文件：** `backend/src/routes/audit-logs.ts`

#### 1. 查询日志接口
```typescript
GET /api/audit-logs
  ?user_id=1
  &action=create
  &resource_type=customer
  &start_time=2026-05-01
  &end_time=2026-05-09
  &page=1
  &limit=50
  &search=关键字
```

**权限控制：**
- 超级管理员：可以查看所有日志
- 其他用户：只能查看自己的日志

**返回数据：**
```json
{
  "logs": [...],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 268,
    "totalPages": 6
  }
}
```

#### 2. 日志详情接口
```typescript
GET /api/audit-logs/:id
```

**权限控制：**
- 超级管理员：可以查看任何日志
- 其他用户：只能查看自己的日志

#### 3. 统计接口
```typescript
GET /api/audit-logs/stats/summary
  ?start_time=2026-05-01
  &end_time=2026-05-09
```

**返回数据：**
```json
{
  "total": 268,
  "today": 15,
  "week": 89,
  "month": 268,
  "actionStats": [
    { "action": "scan", "count": 120 },
    { "action": "create", "count": 45 }
  ],
  "resourceStats": [
    { "resource_type": "scan", "count": 120 },
    { "resource_type": "customer", "count": 30 }
  ]
}
```

#### 4. 导出接口
```typescript
GET /api/audit-logs/export/csv
  ?user_id=1
  &action=create
  &start_time=2026-05-01
  &end_time=2026-05-09
```

**特点：**
- 导出为CSV格式
- 添加UTF-8 BOM支持Excel
- 限制最多导出10000条
- 自动下载文件

## 💡 使用场景

### 场景1：安全审计
**需求：** 检查谁在什么时候做了什么操作

**操作：**
1. 打开审计日志页面
2. 按时间范围筛选
3. 查看操作记录
4. 点击查看详情

### 场景2：问题排查
**需求：** 某个数据被误删，需要找到是谁删的

**操作：**
1. 按操作类型筛选"删除"
2. 按资源类型筛选
3. 查看删除记录
4. 查看详情确认

### 场景3：用户行为分析
**需求：** 分析用户的操作习惯

**操作：**
1. 按用户筛选
2. 查看该用户的所有操作
3. 分析操作频率
4. 导出数据进行分析

### 场景4：合规审计
**需求：** 导出审计日志用于合规检查

**操作：**
1. 设置时间范围（如本月）
