### 1. 用户管理权限收紧 ✅

**问题：**
- qx001（客户管理员）不能删除自己创建的用户 qx002
- 删除时报错：FOREIGN KEY constraint failed
- 客户管理员不应该有用户管理权限

**解决方案：**

#### 后端修改

**文件：** `backend/src/routes/users.ts`

```typescript
// 1. 创建用户 - 改为只有超级管理员可以
router.post('/', requireSuperAdmin, async (req: AuthRequest, res) => {
  // ...
});

// 2. 更新用户 - 改为只有超级管理员可以
router.put('/:id', requireSuperAdmin, async (req: AuthRequest, res) => {
  // ...
});

// 3. 删除用户 - 改为只有超级管理员可以，并检查关联数据
router.delete('/:id', requireSuperAdmin, async (req: AuthRequest, res) => {
  // 检查是否有扫码记录
  const scanCount = db.prepare('SELECT COUNT(*) as count FROM scans WHERE user_id = ?').get(userId);
  if (scanCount.count > 0) {
    return res.status(400).json({ 
      error: `该用户有 ${scanCount.count} 条扫码记录，无法删除。建议禁用该用户。` 
    });
  }
  
  // 检查是否创建了数据
  const customerCount = db.prepare('SELECT COUNT(*) as count FROM customers WHERE created_by = ?').get(userId);
  const productCount = db.prepare('SELECT COUNT(*) as count FROM products WHERE created_by = ?').get(userId);
  
  if (customerCount.count > 0 || productCount.count > 0) {
    return res.status(400).json({ 
      error: `该用户创建了 ${customerCount.count} 个客户和 ${productCount.count} 个产品，无法删除。建议禁用该用户。` 
    });
  }
  
  // 删除用户的权限记录
  db.prepare('DELETE FROM user_product_permissions WHERE user_id = ?').run(userId);
  
  // 删除用户
  db.prepare('DELETE FROM users WHERE id = ?').run(userId);
});
```

### 2. 修改密码功能 ✅

**需求：** 所有用户都能修改自己的密码

**实现：**

#### 后端接口

**文件：** `backend/src/routes/users.ts`

```typescript
// 修改自己的密码
router.put('/me/password', requireAuth, async (req: AuthRequest, res) => {
  const { old_password, new_password } = req.body;
  
  // 验证旧密码
  const isValidPassword = await bcrypt.compare(old_password, currentUser.password_hash);
  if (!isValidPassword) {
    return res.status(400).json({ error: '旧密码错误' });
  }
  
  // 加密新密码
  const new_password_hash = await bcrypt.hash(new_password, 10);
  
  // 更新密码
  db.prepare('UPDATE users SET password_hash = ? WHERE id = ?').run(new_password_hash, user.id);
  
  res.json({ message: '密码修改成功，请重新登录' });
});
```

### 3. 客户/产品编辑功能 ✅

**问题：** 客户管理页面只有删除功能，没有编辑功能

**解决方案：**

#### 客户管理

**文件：** `frontend/src/pages/Customers.tsx`

```tsx
// 1. 改用模态框方式
const [showModal, setShowModal] = useState(false);
const [editingId, setEditingId] = useState<number | null>(null);

// 2. 页面头部添加新增按钮
<div className="page-header">
  <h2>客户维护</h2>
  <button onClick={handleCreate} className="btn-primary">+ 新增客户</button>
</div>

// 3. 列表中添加编辑按钮
{c.can_edit ? (
  <div className="action-buttons">
    <button onClick={() => handleEdit(c)} className="btn-edit">编辑</button>
    <button onClick={() => handleDelete(c.id)} className="btn-delete">删除</button>
  </div>
) : (
  <span className="readonly-badge">只读</span>
)}

// 4. 编辑处理函数
const handleEdit = (customer: Customer) => {
  setEditingId(customer.id);
  setName(customer.name);
  setExpectedLength(customer.expected_length);
  setDescription(customer.description || '');
  setShowModal(true);
};

// 5. 提交时判断是新增还是编辑
if (editingId) {
  await api.put(`/customers/${editingId}`, { name, expected_length: expectedLength, description });
} else {
  await api.post('/customers', { name, expected_length: expectedLength, description });
}
```

## 🔒 安全性提升

### 1. 用户管理权限

**之前：**
- 客户管理员可以创建/修改/删除用户
- 可能误删有数据的用户
- 外键约束导致删除失败

**现在：**
- ✅ 只有超级管理员可以管理用户
- ✅ 删除前检查关联数据
- ✅ 有数据的用户不能删除，建议禁用
- ✅ 自动删除用户的权限记录

### 2. 密码安全

**功能：**
- ✅ 必须提供正确的旧密码
- ✅ 新密码长度至少6位
- ✅ 修改后需要重新登录
- ✅ 所有用户都能修改自己的密码
- ✅ 记录审计日志

### 3. 数据保护

**编辑权限：**
- ✅ 只能编辑自己创建的数据
- ✅ 他人数据显示"只读"
- ✅ 前后端双重验证

## 💡 使用指南

### 1. 修改密码

**步骤：**
1. 点击导航栏的"修改密码"按钮
2. 输入旧密码
3. 输入新密码（至少6位）
4. 确认新密码
5. 点击"确定"
6. 系统提示成功后自动退出
7. 使用新密码重新登录

### 2. 编辑客户

**步骤：**
1. 进入客户管理页面
2. 找到要编辑的客户
3. 点击"编辑"按钮
4. 在弹出的窗口中修改信息
5. 点击"保存"

**注意：**
- 只能编辑自己创建的客户
- 他人创建的客户显示"只读"

### 3. 编辑产品

**步骤：**
1. 进入产品管理页面
2. 找到要编辑的产品
3. 点击"编辑"按钮
4. 修改产品型号和描述
5. 点击"保存"

**注意：**
- 编辑时不能修改关联客户
- 只能编辑自己创建的产品
