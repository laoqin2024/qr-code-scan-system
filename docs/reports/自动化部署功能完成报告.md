## 🚀 使用方式

### 方式1：一键部署（推荐）

```bash

```

### 方式2：下载后执行

```bash
curl -O https://gitee.com/laoqin1/qr-code-scan-system/raw/main/scripts/deploy.sh
chmod +x deploy.sh
./deploy.sh
```

### 方式3：克隆后执行

```bash
git clone https://gitee.com/laoqin1/qr-code-scan-system.git
cd qr-code-scan-system
./scripts/deploy.sh
```

## 🔧 生成的配置

### 1. 环境变量（backend/.env）

```env
PORT=3001
JWT_SECRET=<自动生成>
NODE_ENV=production
```

### 2. Nginx 配置

```nginx
server {
    listen 80;
    server_name 服务器地址;
    
    # 前端静态文件
    location / {
        root /opt/scan-code/frontend/dist;
        try_files $uri $uri/ /index.html;
    }
    
    # API 代理
    location /api {
        proxy_pass http://localhost:3001;
        ...
    }
}
```

### 3. PM2 配置

```bash
pm2 start npm --name "scan-code-backend" -- start
pm2 save
pm2 startup
```
