## 💡 使用指南

### 管理员操作

**创建用户（必须提供姓名）：**
```
1. 进入用户管理页面
2. 点击"新增用户"
3. 填写：
   - 登录账号: operator_zhang
   - 姓名: 张三
   - 密码: password123
   - 角色: 操作员
4. 提交
```

**查看数据创建者：**
```
1. 进入客户管理或产品管理
2. 列表中会显示"创建者"列
3. 显示创建者的姓名
4. 只能编辑自己创建的数据
```

**按录入人员筛选：**
```
1. 进入查询记录页面
2. 在"录入人员"下拉框选择用户
3. 自动筛选该用户的记录
```

### 操作员使用

**扫码时自动记录：**
```
1. 扫码录入
2. 系统自动记录你的姓名
3. 在查询记录中可以看到是你录入的
```

**查看自己的记录：**
```
1. 进入查询记录
2. 自动只显示你录入的记录
3. 显示你的姓名而不是账号
```

## 📞 技术支持

### 常见问题

**Q: 现有用户的姓名是什么？**
A: 默认为用户名，可以在用户管理中修改。

**Q: 现有客户/产品的创建者是谁？**
A: 默认为 admin，实际创建者信息已无法追溯。

**Q: 如何修改用户姓名？**
A: 在用户管理页面点击"编辑"，修改姓名字段。

**Q: 为什么有些数据不能编辑？**
A: 只能编辑自己创建的数据，其他人创建的显示为"只读"。

**Q: 如何查看某个人录入的所有扫码？**
A: 在查询记录页面，使用"录入人员"筛选器。
