# 用户管理多选授权功能完成报告

## ✅ 功能已完成

**需求：** 超级管理员在创建或编辑用户时可以多选客户和产品进行授权，避免权限控制太死

**实施时间：** 2025-01-06  
**版本：** v3.5  
**状态：** ✅ 已完成

---

## 🎯 实施内容

### 功能描述

在用户管理页面的创建/编辑用户模态框中，添加了客户和产品的多选授权功能：

1. **客户级别授权**
   - 点击客户名称，自动选择该客户的所有产品
   - 适合快速授权整个客户

2. **产品级别授权**
   - 可以单独勾选/取消产品
   - 精细控制权限

3. **智能联动**
   - 选择客户时，自动选择该客户的所有产品
   - 取消客户时，自动取消该客户的所有产品
   - 显示选择状态（全选/部分选择/未选择）

## 🔧 技术实现

### 前端实现

**文件：** `frontend/src/pages/Users.tsx`

#### 1. 状态管理

```typescript
const [selectedCustomers, setSelectedCustomers] = useState<number[]>([]);
const [selectedProducts, setSelectedProducts] = useState<number[]>([]);
const [products, setProducts] = useState<Product[]>([]);
```

#### 2. 客户切换处理

```typescript
const handleCustomerToggle = (customerId: number) => {
  if (selectedCustomers.includes(customerId)) {
    // 取消选择客户，同时取消该客户的所有产品
    setSelectedCustomers(selectedCustomers.filter(id => id !== customerId));
    const customerProductIds = products.filter(p => p.customer_id === customerId).map(p => p.id);
    setSelectedProducts(selectedProducts.filter(id => !customerProductIds.includes(id)));
  } else {
    // 选择客户，同时选择该客户的所有产品
    setSelectedCustomers([...selectedCustomers, customerId]);
    const customerProductIds = products.filter(p => p.customer_id === customerId).map(p => p.id);
    setSelectedProducts([...new Set([...selectedProducts, ...customerProductIds])]);
  }
};
```

#### 3. 产品切换处理

```typescript
const handleProductToggle = (productId: number) => {
  if (selectedProducts.includes(productId)) {
    setSelectedProducts(selectedProducts.filter(id => id !== productId));
  } else {
    setSelectedProducts([...selectedProducts, productId]);
  }
};
```

#### 4. 选择状态判断

```typescript
const isCustomerFullySelected = (customerId: number) => {
  const customerProducts = getCustomerProducts(customerId);
  return customerProducts.length > 0 && 
         customerProducts.every(p => selectedProducts.includes(p.id));
};

const isCustomerPartiallySelected = (customerId: number) => {
  const customerProducts = getCustomerProducts(customerId);
  return customerProducts.some(p => selectedProducts.includes(p.id)) && 
         !isCustomerFullySelected(customerId);
};
```

#### 5. 提交时批量授权

```typescript
const handleSubmit = async (e: React.FormEvent) => {
  // ... 创建/更新用户 ...
  
  // 授权产品（如果是 operator 或 viewer）
  if ((formData.role === 'operator' || formData.role === 'viewer') && 
      selectedProducts.length > 0) {
    await permissionAPI.grantPermissionBatch(
      userId,
      selectedProducts,
      true, // can_scan
      true  // can_view
    );
    alert(`创建成功！\n\n已授权 ${selectedProducts.length} 个产品`);
  }
};
```

#### 6. 编辑时加载现有权限

```typescript
const handleEdit = async (user: User) => {
  // ... 设置表单数据 ...
  
  // 加载用户的权限
  const perms = await userAPI.getUserPermissions(user.id);
  const productIds = perms.data.map((p: any) => p.product_id);
  setSelectedProducts(productIds);
  
  // 根据产品找出客户
  const customerIds = [...new Set(
    products
      .filter(p => productIds.includes(p.id))
      .map(p => p.customer_id)
  )];
  setSelectedCustomers(customerIds);
};
```

## 🎨 UI 设计

### 多选授权区域

```tsx
<div className="form-group">
  <label>产品授权（可多选）</label>
  <div style={{
    maxHeight: '300px',
    overflowY: 'auto',
    border: '2px solid #e8e8e8',
    borderRadius: '8px',
    padding: '10px',
    background: '#fafafa'
  }}>
    {customers.map(customer => {
      const customerProducts = getCustomerProducts(customer.id);
      const isFullySelected = isCustomerFullySelected(customer.id);
      const isPartiallySelected = isCustomerPartiallySelected(customer.id);
      
      return (
        <div key={customer.id}>
          {/* 客户级别 */}
          <div style={{
            background: isFullySelected ? '#e3f2fd' : 
                       isPartiallySelected ? '#fff3cd' : 'white',
            cursor: 'pointer'
          }} onClick={() => handleCustomerToggle(customer.id)}>
            <input type="checkbox" checked={isFullySelected} />
            <strong>{customer.name}</strong>
            <span>({customerProducts.length} 个产品)</span>
          </div>
          
          {/* 产品级别 */}
          <div style={{paddingLeft: '30px'}}>
            {customerProducts.map(product => (
              <div key={product.id} 
                   onClick={() => handleProductToggle(product.id)}
                   style={{
                     background: selectedProducts.includes(product.id) ? 
                                '#e8f5e9' : 'transparent'
                   }}>
                <input 
                  type="checkbox" 
                  checked={selectedProducts.includes(product.id)} 
                />
                <span>{product.model}</span>
              </div>
            ))}
          </div>
        </div>
      );
    })}
  </div>
  <small>已选择 {selectedProducts.length} 个产品</small>
</div>
```

### 视觉反馈

**客户选择状态：**

- 未选择：白色背景

**产品选择状态：**

## 📝 API 使用

### 批量授权接口

**路径：** `POST /api/permissions/users/:userId/permissions/products/batch`

**请求体：**
```json
{
  "product_ids": [1, 2, 3, 4, 5],
  "can_scan": true,
  "can_view": true
}
```

**响应：**
```json
{
  "message": "已授权 5 个产品",
  "granted_count": 5
}
```

### 获取用户权限接口

**路径：** `GET /api/permissions/users/:userId/permissions`

**响应：**
```json
[
  {
    "product_id": 1,
    "product_model": "iPhone 15",
    "customer_id": 1,
    "customer_name": "富士康",

]
```
