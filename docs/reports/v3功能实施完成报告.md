### 2. 数据所有权（created_by）

#### 数据库变更
```sql
ALTER TABLE customers ADD COLUMN created_by INTEGER REFERENCES users(id);
ALTER TABLE products ADD COLUMN created_by INTEGER REFERENCES users(id);
CREATE INDEX idx_customers_created_by ON customers(created_by);
CREATE INDEX idx_products_created_by ON products(created_by);
```

#### 权限规则

**客户管理：**
- ✅ 所有客户管理员可以查看所有客户

## 📈 数据迁移

### 现有数据处理

#### 用户表
```sql
-- 现有用户的姓名默认为用户名
UPDATE users SET display_name = 
  CASE 
    WHEN username = 'admin' THEN '系统管理员'
    ELSE username
  END
WHERE display_name IS NULL;
```

#### 客户表
```sql
-- 现有客户的创建者设为 admin
UPDATE customers 
SET created_by = (SELECT id FROM users WHERE role = 'super_admin' LIMIT 1)
WHERE created_by IS NULL;
```

#### 产品表
```sql
-- 现有产品的创建者设为 admin
UPDATE products 
SET created_by = (SELECT id FROM users WHERE role = 'super_admin' LIMIT 1)
WHERE created_by IS NULL;
```
