# 客户管理员数据可见性修复报告

## ✅ 问题已解决

**问题：** qx001 被授权了 3 个产品（属于 2 个客户），但登录后只能看到 1 个客户

**原因：** 客户和产品列表的查询逻辑只显示自己创建的数据，没有包含授权产品的数据

**解决方案：** 修改查询逻辑，让客户管理员可以看到：自己创建的数据 + 授权产品的数据

**实施时间：** 2025-01-06  
**版本：** v3.6.2  
**状态：** ✅ 已完成

## 🎯 问题分析

### 之前的查询逻辑

**客户列表（customers.ts）：**
```typescript
// customer_admin 只能看自己创建的客户
else if (user.role === 'customer_admin') {
```

### 问题

**场景：**
- qx001 创建了客户 A 和产品 P1, P2
- 超级管理员授权 qx001 访问客户 B 的产品 P3
- qx001 的权限：3 个产品（P1, P2, P3），涉及 2 个客户（A, B）

**期望：**
- qx001 应该看到 2 个客户（A, B）
- qx001 应该看到 3 个产品（P1, P2, P3）

**实际（修复前）：**
- ❌ qx001 只看到 1 个客户（A）
- ❌ qx001 只看到 2 个产品（P1, P2）
- ❌ 看不到授权的客户 B 和产品 P3

## 🔧 技术实现

### 后端修改

**文件：** `backend/src/routes/customers.ts`

#### 修改客户列表查询

```typescript
// customer_admin 可以看自己创建的客户 + 授权产品的客户
else if (user.role === 'customer_admin') {
  query = `
    SELECT DISTINCT c.*,
           u.username as created_by_username,
           u.display_name as created_by_display_name,
           CASE WHEN c.created_by = ? THEN 1 ELSE 0 END as can_edit
    FROM customers c
    LEFT JOIN users u ON c.created_by = u.id
    LEFT JOIN products p ON c.id = p.customer_id
    LEFT JOIN user_product_permissions upp ON p.id = upp.product_id AND upp.user_id = ?
    WHERE c.created_by = ? OR upp.user_id = ?
    ORDER BY c.created_at DESC
  `;
  params.length = 0;
  params.push(user.id, user.id, user.id, user.id);
}
```

**逻辑：**
- `c.created_by = ?` - 自己创建的客户
- `OR upp.user_id = ?` - 授权产品的客户
- `DISTINCT` - 去重（一个客户可能有多个授权产品）
- `can_edit` - 只有自己创建的客户可以编辑

**文件：** `backend/src/routes/products.ts`

#### 修改产品列表查询

```typescript
// customer_admin 可以看自己创建的客户的产品 + 授权的产品
else if (user.role === 'customer_admin') {
  query = `
    SELECT DISTINCT p.*, c.name as customer_name,
           u.username as created_by_username,
           u.display_name as created_by_display_name,
           CASE WHEN p.created_by = ? THEN 1 ELSE 0 END as can_edit
    FROM products p
    JOIN customers c ON p.customer_id = c.id
    LEFT JOIN users u ON p.created_by = u.id
    LEFT JOIN user_product_permissions upp ON p.id = upp.product_id AND upp.user_id = ?
    WHERE p.customer_id IN (SELECT id FROM customers WHERE created_by = ?) OR upp.user_id = ?
    ORDER BY p.created_at DESC
  `;
  params.length = 0;
  params.push(user.id, user.id, user.id, user.id);
}
```

**逻辑：**
- `p.customer_id IN (SELECT id FROM customers WHERE created_by = ?)` - 自己创建的客户的产品
- `OR upp.user_id = ?` - 授权的产品
- `DISTINCT` - 去重
- `can_edit` - 只有自己创建的产品可以编辑

## 📊 数据可见性规则

### 客户管理员可见数据

**公式：**
```
可见数据 = 自己创建的数据 + 授权产品的数据
```

**详细规则：**

| 数据类型 | 可见范围 |
|---------|---------|
| 客户 | 自己创建的客户 + 授权产品所属的客户 |
| 产品 | 自己创建的客户的产品 + 授权的产品 |
| 扫码记录 | 自己创建的客户的记录 + 授权产品的记录 |

### 示例

**客户管理员 qx001：**

**创建的数据：**
- 客户 A
- 产品 P1, P2（属于客户 A）

**授权的数据：**
- 产品 P3（属于客户 B）

**可见数据：**
- 客户：A（创建的）, B（授权的）✅
- 产品：P1, P2（创建的）, P3（授权的）✅
- 扫码记录：P1, P2, P3 的所有记录 ✅
