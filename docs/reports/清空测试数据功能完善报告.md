### 之前的问题

**删除顺序不正确：**
```typescript
1. 删除扫码记录
2. 删除产品权限
3. 删除产品
4. 删除客户
5. 删除用户权限
```

**使用了不安全的做法：**
```typescript
db.exec('PRAGMA foreign_keys = OFF'); // ❌ 禁用外键检查
// ... 删除操作 ...

```

**问题：**
- ❌ 外键检查被禁用，可能留下孤立数据
- ❌ 没有删除审计日志
- ❌ 没有处理用户的 customer_id 引用
- ❌ 删除失败但前端看不到错误

### 现在的解决方案

**正确的删除顺序：**
```typescript
1. 删除扫码记录（scans）
2. 删除产品权限（user_product_permissions）
3. 删除产品（products）
4. 删除客户（customers）
5. 删除审计日志（audit_logs）✅ 新增
6. 解除用户引用（users.customer_id）✅ 新增
7. 删除用户（users）
```

**使用事务保证一致性：**
```typescript
db.exec('BEGIN TRANSACTION');
try {
  // ... 删除操作 ...
  db.exec('COMMIT');
} catch (error) {
  db.exec('ROLLBACK');
  throw error;
}
```

## 🔧 技术实现

### 后端修改

#### 完善的清空逻辑

```typescript
router.post('/cleanup-test-data', requireAuth, async (req: AuthRequest, res) => {
  const db = getDb();
  db.exec('BEGIN TRANSACTION');
  
  try {
    // 1. 查找测试数据
    const testCustomers = db.prepare(`
      SELECT id FROM customers 
      WHERE name LIKE '%测试%' OR name LIKE '%test%'
    `).all();
    
    const testProducts = db.prepare(`
      SELECT id FROM products 
      WHERE model LIKE '%测试%' OR model LIKE '%test%'
    `).all();
    
    const testUsers = db.prepare(`
      SELECT id FROM users 
      WHERE (username LIKE '%test%' OR display_name LIKE '%测试%') AND id != 1
    `).all(); // 保留 admin
    
    // 2. 删除扫码记录
    for (const customer of testCustomers) {
      db.prepare('DELETE FROM scans WHERE customer_id = ?').run(customer.id);
    }
    for (const product of testProducts) {
      db.prepare('DELETE FROM scans WHERE product_id = ?').run(product.id);
    }
    for (const user of testUsers) {
      db.prepare('DELETE FROM scans WHERE user_id = ?').run(user.id);
    }
    
    // 3. 删除产品权限
    for (const product of testProducts) {
      db.prepare('DELETE FROM user_product_permissions WHERE product_id = ?').run(product.id);
    }
    for (const user of testUsers) {
      db.prepare('DELETE FROM user_product_permissions WHERE user_id = ?').run(user.id);
    }
    
    // 4. 删除产品
    for (const customer of testCustomers) {
      const products = db.prepare('SELECT id FROM products WHERE customer_id = ?').all(customer.id);
      for (const product of products) {
        db.prepare('DELETE FROM products WHERE id = ?').run(product.id);
      }
    }
    for (const product of testProducts) {
      db.prepare('DELETE FROM products WHERE id = ?').run(product.id);
    }
    
    // 5. 删除客户
    for (const customer of testCustomers) {
      db.prepare('DELETE FROM customers WHERE id = ?').run(customer.id);
    }
    
    // 6. 删除审计日志 ✅ 新增
    for (const user of testUsers) {
      db.prepare('DELETE FROM audit_logs WHERE user_id = ?').run(user.id);
    }
    
    // 7. 解除用户引用 ✅ 新增
    for (const user of testUsers) {
      db.prepare('UPDATE users SET customer_id = NULL WHERE customer_id IN (SELECT id FROM customers WHERE created_by = ?)').run(user.id);
    }
    
    // 8. 删除用户
    for (const user of testUsers) {
      db.prepare('DELETE FROM users WHERE id = ?').run(user.id);
    }
    
    db.exec('COMMIT');
    
    res.json({ 
      deleted_customers: testCustomers.length,
      deleted_products: testProducts.length,
      deleted_users: testUsers.length,
      deleted_scans: deletedScans,
      deleted_permissions: deletedPermissions,
      deleted_audit_logs: deletedAuditLogs
    });
  } catch (error) {
    db.exec('ROLLBACK');
    throw error;
  }
});
```

## 📊 依赖关系处理

### 数据库表依赖关系

```
users (被引用)
  ↑
  ├── scans.user_id
  ├── customers.created_by
  ├── products.created_by
  ├── users.created_by (自引用)
  ├── users.customer_id → customers.id
  ├── user_product_permissions.user_id
  └── audit_logs.user_id

customers (被引用)
  ↑
  ├── products.customer_id
  ├── scans.customer_id
  └── users.customer_id

products (被引用)
  ↑
  ├── scans.product_id
  └── user_product_permissions.product_id
```

### 正确的删除顺序

```
1. scans (最底层，不被其他表引用)
2. user_product_permissions (不被其他表引用)
3. products (被 scans 和 permissions 引用，已删除)
4. customers (被 products 和 users 引用)
5. audit_logs (引用 users，但不阻止删除)
6. 解除 users.customer_id 引用
7. users (最后删除)
```

## 💡 设计原则

### 1. 事务保证一致性

**使用事务：**
```typescript
db.exec('BEGIN TRANSACTION');
try {
  // 所有删除操作
  db.exec('COMMIT');
} catch (error) {
  db.exec('ROLLBACK'); // 失败回滚
  throw error;
}
```

**优势：**
- ✅ 要么全部成功，要么全部失败
- ✅ 不会留下部分删除的数据
- ✅ 数据一致性有保证

### 2. 正确处理外键

**不禁用外键检查：**
```typescript
// ❌ 错误做法
db.exec('PRAGMA foreign_keys = OFF');

// ✅ 正确做法
// 按正确顺序删除，尊重外键约束
```

**优势：**
- ✅ 外键约束保护数据完整性
- ✅ 及时发现依赖关系问题
- ✅ 不会留下孤立数据

### 3. 保护重要数据

**保留 admin 账号：**
```typescript
const testUsers = db.prepare(`
  SELECT id FROM users 
  WHERE (username LIKE '%test%' OR display_name LIKE '%测试%')

`).all();
```

**优势：**
- ✅ 防止误删管理员账号
- ✅ 系统始终可用
- ✅ 安全性保证

### 4. 完整的清理

**清理所有相关数据：**

- ✅ 产品
