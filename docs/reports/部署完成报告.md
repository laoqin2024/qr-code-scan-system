## 📝 使用指南

### 1. 登录系统
访问 http://localhost:5173，使用 admin / admin123 登录

### 2. 创建客户（超级管理员）
1. 点击"客户管理"
2. 点击"新增客户"
3. 填写客户信息

### 3. 创建产品（管理员）
1. 点击"产品管理"
2. 点击"新增产品"
3. 选择客户，填写产品信息

### 4. 创建操作员（管理员）
1. 点击"用户管理"
2. 点击"新增用户"
3. 选择角色为"操作员"
4. 选择所属客户

### 5. 授权产品（管理员）
1. 在"用户管理"中找到操作员
2. 点击"权限配置"（需要实现）
3. 选择可以扫描的产品

### 6. 扫码录入（操作员）
1. 点击"扫码录入"
2. 选择产品
3. 扫描或输入条码

### 7. 查询记录
1. 点击"查询记录"
2. 设置筛选条件
3. 查看扫码记录

## 🐛 故障排查

### 问题1: 登录 500 错误
**原因**: 数据库未迁移或依赖包缺失
**解决**: 
```bash
cd backend
npm install better-sqlite3 @types/better-sqlite3
npm run migrate
```

### 问题2: 用户被禁用
**原因**: 数据库中 is_active 字段为 0
**解决**:
```bash
sqlite3 db.sqlite "UPDATE users SET is_active = 1 WHERE username = 'admin';"
```

### 问题3: 密码错误
**原因**: 密码哈希不匹配
**解决**: 重置密码（见使用指南）
