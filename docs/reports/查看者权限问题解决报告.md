**实施自动授权功能**

#### 实现内容

**后端修改：** `backend/src/routes/users.ts`

```typescript
// 创建用户后，如果是 viewer 或 operator，自动授权产品
if (role === 'viewer' || role === 'operator') {
  let products: any[] = [];
  
  if (user.role === 'super_admin') {
    // super_admin 创建的用户，授权所有产品
    products = db.prepare('SELECT id FROM products').all();
  } else if (user.role === 'customer_admin') {
    if (finalCustomerId) {
      // 授权指定客户的所有产品
      products = db.prepare('SELECT id FROM products WHERE customer_id = ?').all(finalCustomerId);
    } else if (user.customer_id) {
      // 授权创建者客户的所有产品
      products = db.prepare('SELECT id FROM products WHERE customer_id = ?').all(user.customer_id);
    } else {
      // 授权创建者有权限的所有产品
      products = db.prepare(`
        SELECT DISTINCT product_id as id FROM user_product_permissions
        WHERE user_id = ?
      `).all(user.id);
    }
  }
  
  // 批量授权
  const canScan = role === 'operator' ? 1 : 0;
  for (const product of products) {
    stmt.run(newUserId, product.id, canScan, 1);
  }
}
```

## 📊 自动授权规则

### 规则说明

| 创建者角色 | 创建的用户 | 自动授权的产品 |
|-----------|-----------|--------------|
| super_admin | viewer/operator | 所有产品 |
| customer_admin | viewer/operator | 创建者客户的所有产品 |
| customer_admin（无客户） | viewer/operator | 创建者有权限的所有产品 |

| 角色 | 可以扫码 | 可以查看 |
|------|---------|---------|

## 📞 常见问题

**Q: 为什么 qx002 之前看不到记录？**
A: viewer 需要先被授权产品才能查看记录，之前没有自动授权功能。

**Q: 现在创建 viewer 会自动授权吗？**
A: 是的，创建 viewer 或 operator 时会自动授权创建者有权限的所有产品。

**Q: 自动授权的产品可以修改吗？**
A: 可以，管理员可以后续添加或移除产品权限。

**Q: super_admin 创建的 viewer 会授权所有产品吗？**
A: 是的，super_admin 创建的 viewer/operator 会自动授权所有产品。

**Q: 如果不想自动授权怎么办？**
A: 目前自动授权是默认行为，如需禁用可以联系管理员。
