### 1. 下拉列表权限过滤 ✅

**问题：**
- 操作员和客户管理员在查询页面看到所有客户和产品
- 无权限的选项造成干扰
- 用户体验不好

**解决方案：**

#### 客户管理员
- **之前：** 可以看到所有客户和产品
- **现在：** 只能看到自己创建的客户和产品

**后端修改：** `backend/src/routes/customers.ts`
```typescript
// customer_admin 只能看自己创建的客户
else if (user.role === 'customer_admin') {
  query += ' WHERE c.created_by = ? ORDER BY c.created_at DESC';
  params.push(user.id);
}
```

**后端修改：** `backend/src/routes/products.ts`
```typescript
// customer_admin 只能看自己创建的客户的产品
else if (user.role === 'customer_admin') {
  query += ' WHERE p.customer_id IN (SELECT id FROM customers WHERE created_by = ?) ORDER BY p.created_at DESC';
  params.push(user.id);
}
```

#### 操作员和查看者
- **之前：** 已经有权限过滤（只看授权的）
- **现在：** 保持不变

**逻辑：**
```typescript
// operator/viewer 只能看授权的产品
else if (user.role === 'operator' || user.role === 'viewer') {
  query = `
    SELECT DISTINCT c.*
    FROM customers c
    JOIN products p ON c.id = p.customer_id
    JOIN user_product_permissions upp ON p.id = upp.product_id
    WHERE upp.user_id = ?
  `;
}
```

### 2. 修复超级管理员查询权限 ✅

**问题：**
- 超级管理员查询扫码记录时可能受到限制

**解决方案：**

**后端修改：** `backend/src/routes/scans.ts`
```typescript
// 根据角色过滤数据
if (user.role === 'super_admin') {
  // super_admin 可以看所有记录（不添加任何过滤条件）
} else if (user.role === 'customer_admin') {
  // customer_admin 可以看自己创建的客户的产品记录 + 有权限的产品记录
  query += ` AND (
    s.customer_id IN (SELECT id FROM customers WHERE created_by = ?)
    OR s.product_id IN (SELECT product_id FROM user_product_permissions WHERE user_id = ? AND can_view = 1)
  )`;
  params.push(user.id, user.id);
}
```

**改进：**
- 超级管理员不受任何限制
- 客户管理员可以看到自己创建的客户的所有扫码记录
- 客户管理员也可以看到授权产品的扫码记录

### 3. 添加删除单条记录按钮 ✅

**功能描述：**
- 在查询页面的每条记录后添加删除按钮
- 只有超级管理员可以看到和使用
- 删除前需要确认

**前端实现：** `frontend/src/pages/Query.tsx`

#### 1. 获取当前用户角色
```typescript
const [currentUserRole, setCurrentUserRole] = useState<UserRole | null>(null);

useEffect(() => {
  const userStr = localStorage.getItem('user');
  if (userStr) {
    const user = JSON.parse(userStr);
    setCurrentUserRole(user.role);
  }
}, []);
```

#### 2. 添加操作列
```tsx
<thead>
  <tr>
    <th>客户</th>
    <th>产品</th>
    {/* ... 其他列 ... */}
    {currentUserRole === 'super_admin' && <th>操作</th>}
  </tr>
</thead>
```

#### 3. 添加删除按钮
```tsx
{currentUserRole === 'super_admin' && (
  <td>
    <button onClick={() => handleDelete(s.id)} className="btn-delete-small">
      删除
    </button>
  </td>
)}
```

#### 4. 删除处理函数
```typescript
const handleDelete = async (id: number) => {
  if (!window.confirm('确定要删除这条扫码记录吗？')) return;
  
  try {
    await scanAPI.deleteScan(id);
    alert('删除成功');
    fetchScans();
  } catch (err: any) {
    alert(err.response?.data?.error || '删除失败');
  }
};
```

**样式：** `frontend/src/styles/Page.css`
```css

  color: white;

  cursor: pointer;
  font-size: 11px;
  font-weight: 600;
  transition: all 0.3s ease;
  box-shadow: 0 2px 8px rgba(244, 67, 54, 0.3);
}
```
