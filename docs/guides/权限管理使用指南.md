# 权限管理系统 - 使用指南

## 一、快速开始

### 1. 全新安装

如果是全新系统，执行：

```bash
cd backend
npm run init-v2
npm run dev
```

### 2. 从旧系统升级

如果已有旧数据库，执行迁移：

```bash
cd backend
npm run migrate
npm run dev
```

迁移脚本会：
- 自动备份现有数据库到 `db.sqlite.backup`
- 升级表结构
- 转换旧角色（admin → super_admin）
- 保留所有现有数据

## 二、角色说明

### 1. 超级管理员 (super_admin)

**权限范围：**
- 管理所有客户
- 管理所有产品
- 管理所有用户
- 查看所有扫码记录
- 查看审计日志

**典型使用场景：**
- 系统管理员
- 公司IT部门

**测试账号：**
```
用户名: admin
密码: admin123
```

### 2. 客户管理员 (customer_admin)

**权限范围：**
- 管理自己客户的产品
- 创建/管理自己客户下的操作员和查看者
- 为操作员授权产品
- 查看自己客户的所有扫码记录
- 可以扫码录入

**典型使用场景：**
- 客户方的项目经理
- 生产线主管

**测试账号：**
```
用户名: foxconn_manager (富士康)
密码: manager123

用户名: byd_manager (比亚迪)
密码: manager123
```

### 3. 操作员 (operator)

**权限范围：**
- 扫码录入授权的产品
- 查看自己扫描的记录
- 不能修改客户/产品信息

**典型使用场景：**
- 生产线工人
- 质检员

**测试账号：**
```
用户名: operator_zhang (富士康)
密码: operator123
可扫描: iPhone 15 Pro, iPad Air

用户名: operator_li (比亚迪)
密码: operator123
可扫描: 海豹电池模组
```

### 4. 查看者 (viewer)

**权限范围：**
- 只读查看授权产品的扫码记录
- 不能扫码
- 不能修改任何数据

**典型使用场景：**
- 质量分析师
- 报表查看人员

**测试账号：**
```
用户名: viewer_wang (富士康)
密码: viewer123
可查看: iPhone 15 Pro 记录
```

## 三、API 接口

### 认证接口

```bash
# 登录
POST /api/auth/login
{
  "username": "admin",
  "password": "admin123"
}

# 获取当前用户信息
GET /api/auth/me
Authorization: Bearer <token>

# 修改密码
POST /api/auth/change-password
{
  "old_password": "admin123",
  "new_password": "newpassword"
}

# 登出
POST /api/auth/logout
```

### 用户管理

```bash
# 获取用户列表（按权限过滤）
GET /api/users

# 获取单个用户
GET /api/users/:id

# 创建用户
POST /api/users
{
  "username": "new_user",
  "password": "password123",
  "role": "operator",
  "customer_id": 1
}

# 更新用户
PUT /api/users/:id
{
  "password": "newpassword",
  "is_active": true
}

# 删除用户
DELETE /api/users/:id
```

### 权限管理

```bash
# 获取用户的产品权限
GET /api/permissions/users/:id/permissions

# 授权产品给用户
POST /api/permissions/users/:id/permissions/products
{
  "product_id": 1,
  "can_scan": true,
  "can_view": true
}

# 批量授权
POST /api/permissions/users/:id/permissions/products/batch
{
  "product_ids": [1, 2, 3],
  "can_scan": true,
  "can_view": true
}

# 撤销权限
DELETE /api/permissions/users/:id/permissions/products/:productId

# 查看产品的授权用户
GET /api/permissions/products/:id/users
```

### 客户管理

```bash
# 获取客户列表（按权限过滤）
GET /api/customers

# 创建客户（仅超级管理员）
POST /api/customers
{
  "name": "新客户",
  "expected_length": 20,
  "description": "描述"
}

# 更新客户
PUT /api/customers/:id

# 删除客户
DELETE /api/customers/:id
```

### 产品管理

```bash
# 获取产品列表（按权限过滤）
GET /api/products

# 创建产品（管理员）
POST /api/products
{
  "model": "产品型号",
  "customer_id": 1,
  "description": "描述"
}

# 更新产品
PUT /api/products/:id

# 删除产品
DELETE /api/products/:id
```

### 扫码录入

```bash
# 扫码录入
POST /api/scans
{
  "customer_id": 1,
  "product_id": 1,
  "code_text": "12345678901234567890",
  "notes": "备注"
}

# 查询记录（按权限过滤）
GET /api/scans?customer_id=1&product_id=1&start_time=2024-01-01

# 获取统计
GET /api/scans/stats?customer_id=1&product_id=1
```

### 审计日志

```bash
# 获取审计日志（管理员）
GET /api/permissions/audit-logs?limit=100&offset=0

# 获取我的操作记录
GET /api/permissions/audit-logs/my
```

## 四、典型工作流程

### 场景1：新增客户和操作员

```bash
# 1. super_admin 创建客户
POST /api/customers
{
  "name": "华为",
  "expected_length": 22,
  "description": "通信设备"
}
# 返回: { "id": 3 }

# 2. super_admin 创建客户管理员
POST /api/users
{
  "username": "huawei_manager",
  "password": "manager123",
  "role": "customer_admin",
  "customer_id": 3
}
# 返回: { "id": 10 }

# 3. 客户管理员登录，创建产品
POST /api/products
{
  "model": "5G基站",
  "customer_id": 3,
  "description": "通信基站"
}
# 返回: { "id": 5 }

# 4. 客户管理员创建操作员
POST /api/users
{
  "username": "operator_zhao",
  "password": "operator123",
  "role": "operator"
  # customer_id 自动设置为管理员的客户
}
# 返回: { "id": 11 }

# 5. 客户管理员授权操作员
POST /api/permissions/users/11/permissions/products
{
  "product_id": 5,
  "can_scan": true,
  "can_view": true
}

# 6. 操作员登录，开始扫码
POST /api/scans
{
  "customer_id": 3,
  "product_id": 5,
  "code_text": "1234567890123456789012"
}
```

### 场景2：多客户并行作业

```
工位1: operator_zhang (富士康) → 扫 iPhone 15 Pro
工位2: operator_li (比亚迪) → 扫 海豹电池模组

```

## 五、安全建议

### 1. 密码策略

- 生产环境必须修改默认密码
- 建议密码长度至少 8 位
- 包含字母、数字、特殊字符
- 定期更换密码

### 2. Token 管理

- JWT token 有效期 8 小时
- 前端应处理 token 过期情况
- 敏感操作建议二次验证

### 3. 权限最小化

- 操作员只授权必要的产品
- 查看者只授权必要的查看权限
- 定期审查用户权限

### 4. 审计日志

- 定期检查审计日志
- 关注异常登录和操作
- 保留日志至少 6 个月

## 六、故障排查

### 问题1：迁移失败

**解决方案：**
```bash
# 1. 检查备份文件
ls -lh db.sqlite.backup

# 2. 手动恢复
cp db.sqlite.backup db.sqlite

# 3. 查看错误日志
npm run migrate 2>&1 | tee migrate.log
```

### 问题2：权限不生效

**检查清单：**
1. 用户是否激活（is_active = 1）
2. 用户是否关联正确的客户
3. 操作员是否被授权产品
4. JWT token 是否包含正确的角色和客户ID

### 问题3：无法登录

**可能原因：**
1. 用户被禁用 → 联系管理员激活
2. 密码错误 → 联系管理员重置
3. Token 过期 → 重新登录

## 七、性能优化

系统已创建以下索引：
- users(customer_id, role)
- products(customer_id)
- scans(user_id, product_id, created_at)
- user_product_permissions(user_id, product_id)
- audit_logs(user_id, created_at)

建议：
- 查询时使用索引字段
- 大量数据时使用分页
- 定期清理旧的审计日志
